Professional work · code confidential

AWS ETL Pipeline

An event-driven pipeline where the only manual step is dropping in the monthly file. Files cleaned by AI agents land in the Amazon S3 data lake via Power Automate. EventBridge triggers Lambda to validate schema, nulls and business rules, and bad files stop the run with an SNS email alert. Glue checks the file hasn't been loaded before, stamps it and appends rows to the Aurora Serverless PostgreSQL data warehouse, which is queried live with Amazon Athena (Federated Query) and Power BI.
